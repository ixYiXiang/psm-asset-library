- 正式牌池：89 张
- 默认主牌组：36 张 + 3 张设施蓝图
- 四个流派：连续性、代理、蒸馏、组件
- v0.10.6 重点：针对性克制与隐藏弱点审计
- Godot 尚未启动；HTML 仍是当前规则与体验验证平台

## GitHub 归档内容

- `docs/`：本版更新说明、设计决策、隐藏弱点报告、工程门禁、阶段集中讨论与交接

正式可玩 HTML 与完整 188 文件研发 ZIP 仍保留在本地交付包中；GitHub 这里作为长期版本备份与源码恢复点，不重复塞入大量历史测试基线。
