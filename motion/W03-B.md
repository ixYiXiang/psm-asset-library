# W03-B｜非重复运动美术资产扩展

本轮在 W03-A 的 36 项基础上新增 12 项 PSM Code Lab 原创运动美术资产，稳定编号为 `PSM-MO-037` 至 `PSM-MO-048`。合并后 Motion Lab 共 48 项，其中 40 项原创、8 项 Uiverse MIT 改造项。

## 去重原则

新增项必须至少改变以下一项核心机制：

- 几何结构：折纸面、液体容器、层析切片、磁场线、极坐标轨道等。
- 状态模型：粒子由离散归位、版本刻度推进、原生单选标记迁移等。
- 输入映射：指针控制层析窗口或场线，滑杆驱动真实波形振幅。
- 光学表达：纤维方向场与折射焦散，而不是换色后的网格、粒子或涡流。

只改变颜色、阴影、圆角、文字或动画时长，不算新增资产。

## 技术边界

- 所有运行资源均在仓库内，不加载远程脚本、样式、字体或图片。
- 自动循环支持页面级暂停，并受 `prefers-reduced-motion` 控制。
- 指针与表单交互只改变固定预览容器内部状态，不改变卡片尺寸、热区和页面布局。
- 12 项均为 PSM Code Lab 原创实现，不新增第三方许可负担。
