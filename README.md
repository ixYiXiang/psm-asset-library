# PSM Asset Library

「AI 编程日志」项目的公开 PNG 美术资产库。

## 分类

- `BG`、`FX`、`MT`、`IL`、`ES`、`BD`、`PR`

## 固定原始文件地址

- `https://raw.githubusercontent.com/ixYiXiang/psm-asset-library/main/assets/BG/PSM-BG-001.png`
- `https://raw.githubusercontent.com/ixYiXiang/psm-asset-library/main/assets/BG/PSM-BG-002.png`

## 规则

- 文件名使用 `PSM-{分类}-{三位编号}.png`。
- 已发布文件路径保持稳定。
- 透明 PNG 原样提交，不重新编码，不改变 Alpha 通道。
- 资产信息统一登记在 `assets/manifest.json`。

网页启用 GitHub Pages 后位于：`https://ixyixiang.github.io/psm-asset-library/`
